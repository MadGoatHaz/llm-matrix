6. ISSUES FOUND AND FIXED DURING QA
----------------------------------------------------------------
Zero-tolerance link audit found 4 real defects in the merged
code. All were fixed on main, the site re-generated, goldens
re-captured, and the full suite re-run (186/186).

  ISSUE 1 — Guide "Related guides" auto-links 404'd.
    tools/site/guides.py::_related_links emitted href="{slug}/"
    from a depth-2 page (guides/<slug>/index.html), resolving to
    guides/<slug>/<sibling>/ — nonexistent.
    FIX: prefix sibling hrefs with "../" (../<slug>/).

  ISSUE 2 — Hand-written cross-links in 8 guide markdown files
    404'd (25 links, e.g. [KV Cache](kv-cache/) from
    guides/quantization/index.html).
    FIX: new post-render pass tools/site/guides.py::
    _fixup_sibling_links() rewrites any <a href> that is exactly
    a known sibling-guide slug to "../<slug>/". Scope-limited:
    only links to guides that actually exist are rewritten (a
    typo stays a visible 404); anchors/external/already-prefixed
    paths untouched. Depth-1 guides/index.html and root-relative
    links (../../guides/...) are unaffected.

  ISSUE 3 — /api/ docs page and About page linked to
    nonexistent paths (v1/schema.json, api/v1/schema.json).
    The canonical endpoints live at data/api/v1/ (per
    data/api/README.md).
    FIX: tools/site/pages/api.py (2 hrefs + docstring),
    tools/site/pages/about.py (1 href), content/api.md
    (2 raw-HTML hrefs + endpoint code text) now point to
    ../data/api/v1/... (depth 1) and data/api/v1/... (root).

  ISSUE 4 — guides.html redirect stub had the stale pre-P1-9
    nav (plain "Guides" link, no dropdown), inconsistent with
    the other 17 pages.
    FIX: guides_index.render() now accepts and forwards
    guides_menu to page_shell; tools/site/__init__.py passes it.
    Nav verified identical across all 18 pages.

  MINOR (noted, not fixed — cosmetic, no 404):
    - content/guides/model-architectures.md line 116: a markdown
      link inside a raw-HTML <div class="diagram-cell"> is not
      processed by the markdown lib and renders as literal text
      "[Context Extension](context-extension/)". Decorative
      diagram cell only; no broken link. Candidate for a future
      content pass.
