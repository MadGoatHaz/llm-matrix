ℹ️ Reading the matrix

Click any column header to sort (within each tier), or use the Sort dropdown for VRAM, model size, speed, or date across the whole table. Cells show the full value on hover. Speed is community-reported decode throughput; Context is the stable context tested; KV is the KV-cache precision; Mode is how the engine splits weights across VRAM/RAM/SSD. All data is community-reported — treat numbers as user-experienced, not lab-tested. Discussion lives in the forum thread →

The search box covers every field — model name, notes, hardware, backend, quant, use case. Backend and use case are multi-select: tick several, and they combine as any-of within the list and all-of across the other filters. Active filters appear as chips below the bar (each has an ✕), and the count line tells you exactly what you're seeing.

Click any row (or its ⓘ button) to open the full submission — complete hardware, the submitter's notes, a launch command, and a deep link straight to the forum post. The 🔗 Share button copies a link to this exact view — every filter, the sort, and the search included — so you can paste it in the forum and others land on the same table.

The Actions column: ⓘ opens the detail panel, tick the checkbox to add a row to a comparison, or hit 🚀 to copy a launch command for that setup.
